# Security policy

## Project status

Tree Counter is under active development and is not yet ready for production installation. Security support is best effort until the first tested release.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Contact the maintainer privately through the email address listed in the plugin metadata, including a description, reproduction steps, affected versions, and any mitigation you know.

Do not send raster imagery, model files, credentials, or other sensitive data with a report. The plugin is intended to process imagery and models locally; it does not upload them automatically.
